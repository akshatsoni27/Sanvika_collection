# Sanvika Collection — Project Guidelines

Sanvika Collection is a luxury Indian ethnic wear boutique catalog built with TanStack Start, React, Vite, and Tailwind CSS.

### Tech Stack:
- **Framework**: TanStack Start / React Router
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Database / Backend**: Supabase
- **Icons**: Lucide React
