## 🌟 Highlights

- 🛍️ **Interactive Product Showcase** — High-res galleries, dynamic sorting, live search, and price/category filters.
- 💬 **1-Click Social Commerce** — Auto-generated WhatsApp order inquiries (with pre-filled product name, SKU & price) and Instagram DM buttons.
- 🛡️ **Admin Portal (`/admin`)** — Manage products, categories, pricing, and toggle *Featured* / *New Arrival* / *In Stock* tags.
- ⚡ **Full-Stack SSR** — Powered by TanStack Start, TanStack Router, Vite, and Nitro for lightning-fast page loads.
- 🎨 **Luxury Aesthetic** — Warm ivory/maroon palette, Cormorant Garamond typography, and responsive mobile-first UI.

## 🚀 Quick Start

```bash
# 1. Clone & install
git clone https://github.com/akshatsoni27/Sanvika_collection.git
cd Sanvika_collection
npm install

# 2. Configure environment (.env)
VITE_SUPABASE_URL="https://your-project.supabase.co"
VITE_SUPABASE_PUBLISHABLE_KEY="your-publishable-key"

# 3. Run locally
npm run dev
```

## 🛠️ Tech Stack

| Category | Tools & Libraries |
|---|---|
| **Frontend** | React 19, TypeScript, Tailwind CSS v4, shadcn/ui, Lucide Icons |
